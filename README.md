# 🎨 OpenCanvas (Runnable Demo)

This is a **working demo** of OpenCanvas.

## What works
- Frontend loads in browser
- Backend API runs
- Editor page renders a basic canvas
- API health check

## Run locally

### Backend
```bash
cd apps/api
npm install
npm run start:dev
```

### Frontend
```bash
cd apps/web
npm install
npm run dev
```

Open http://localhost:3000
